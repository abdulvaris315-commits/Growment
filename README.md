# GROWMENT ADVERTISING STUDIO

A modern advertising studio web application built with React, Vite, Tailwind CSS, GSAP (ScrollTrigger), Lenis smooth scrolling, and Framer Motion.

## 🚀 Quick Start (Local Development)

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```

4. **Preview Production Build**:
   ```bash
   npm run preview
   ```

---

## 🌐 Deploy to Vercel via GitHub

1. **Push to GitHub**:
   - Create a new repository on GitHub (e.g. `growment-studio`).
   - Push this project to the `main` branch.

2. **Deploy on Vercel**:
   - Go to [vercel.com](https://vercel.com) and log in.
   - Click **Add New** → **Project**.
   - Select your GitHub repository (`growment-studio`).
   - Vercel automatically detects the **Vite** framework preset:
     - **Build Command**: `npm run build`
     - **Output Directory**: `dist`
     - **Install Command**: `npm install`
   - Click **Deploy**!
